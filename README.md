# Blackjack Hi-Lo Calculator

Un'applicazione web progettata per assistere i giocatori di blackjack nel calcolo delle probabilità di uscita di carte alte o basse, basata sul sistema di conteggio Hi-Lo.

## Caratteristiche principali

- **Calcolo probabilità**: Analisi in tempo reale della probabilità di uscita di carte alte o basse.
- **Personalizzazione**: Supporta il numero di mazzi e giocatori scelti dall'utente.
- **Simulazione live**: Simula un tavolo live di blackjack, consentendo di tenere traccia delle carte giocate.
- **UI moderna**: Interfaccia responsive e accattivante sviluppata con React e Tailwind CSS.

## Tecnologie utilizzate

- **React.js**: Per la gestione dell'interfaccia utente.
- **Tailwind CSS**: Per lo stile e il layout responsive.
- **JavaScript**: Per la logica di calcolo Hi-Lo e l'interattività.

## Obiettivi del progetto

1. Implementare un sistema di conteggio Hi-Lo efficace per il blackjack.
2. Sperimentare l'uso di **Tailwind CSS** per il design dell'applicazione.
3. Fornire un'esperienza utente intuitiva e dinamica.

## Come usare l'applicazione

1. Imposta il numero di mazzi e di giocatori.
2. Inserisci le carte man mano che vengono distribuite.
3. Ottieni aggiornamenti in tempo reale sulle probabilità e sul conteggio Hi-Lo.
