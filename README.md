# blackjack-hi-lo-calculator
Un'applicazione interattiva in React per calcolare le probabilità nel blackjack con il sistema Hi-Lo. Permette di tenere traccia delle carte giocate, considerando il numero di mazzi e giocatori, fornendo stime in tempo reale sull'uscita di carte alte o basse. Il progetto utilizza Tailwind CSS per la mia prima volta.
